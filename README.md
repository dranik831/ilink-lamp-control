# iLink lamp control

Управление люстрой iLink по Bluetooth (BLE) через HTTP-сервер.

## Файлы

| Файл | Назначение |
|---|---|
| `lamp_server.py` | Постоянный сервер: держит BLE-соединение с люстрой, управляет по HTTP |
| `test_off.py` | Разовый тест: подключиться и отправить команду выключения света |
| `test_scan.py` | Сканер BLE-устройств (если подключение падает с `BleakDeviceNotFoundError`) |

## Установка

```bash
python -m venv venv
venv\Scripts\pip install bleak
```

## Запуск сервера

```bash
venv\Scripts\python lamp_server.py
```

Управление (порт 3883):

```
http://<ip-сервера>:3883/lamp/on                      — включить
http://<ip-сервера>:3883/lamp/off                     — выключить
http://<ip-сервера>:3883/lamp/brightness?val=128      — яркость (0-255)
http://<ip-сервера>:3883/lamp/rgb?r=255&g=100&b=0     — цвет
http://<ip-сервера>:3883/lamp/warmth?val=200          — температура (0=холодный, 255=тёплый)
http://<ip-сервера>:3883/lamp/status                  — состояние подключения
```

## Если лампа не находится

1. `python test_scan.py` — проверить, видна ли люстра в эфире.
2. Разорвать соединение с приложением на телефоне (одновременно держать связь может только одно устройство).
3. Убедиться, что люстра под напряжением (не выключена выключателем).

## Протокол

Формат пакета: `55 AA` + тело + контрольная сумма `(0x100 - сумма тела) & 0xFF`.
Характеристика для записи: `0000a040-0000-1000-8000-00805f9b34fb`.
Перед командами отправляются пакеты инициализации `INIT1`, `INIT2`.
